# Support Policy — Cambodia Trusted AI Document Platform

> **Status:** Active pre-release support guidance.

---

## 1. Best-Effort Community Support

The **Cambodia Trusted AI Document Platform** is an open-source project maintained by a solo developer. Support is provided on a **best-effort basis**. There are no guaranteed response times or SLA commitments.

---

## 2. Where to Get Help

| Need | Channel | Guidance |
|---|---|---|
| **Questions & Discussions** | GitHub Discussions | Ask general questions, discuss architecture, or share usage ideas. |
| **Bug Reports** | GitHub Issues | Report confirmed bugs using the [Bug Report template](.github/ISSUE_TEMPLATE/bug_report.yml). |
| **Feature Requests** | GitHub Issues | Submit ideas using the [Feature Request template](.github/ISSUE_TEMPLATE/feature_request.yml). |
| **Security Vulnerabilities** | Private Security Disclosure | Follow [SECURITY.md](SECURITY.md). **Never post vulnerabilities in public issues.** |

---

## 3. Security & Sensitive Information

- **Never post sensitive data publicly.** Do not include API keys, credentials, tokens, real personal data, NSSF numbers, or government document contents in issue reports or public discussions.
- All logs, configuration snippets, and error tracebacks attached to support requests must be thoroughly sanitized.

---

## 4. Production Readiness & Paid Support

> **Pre-Release Notice:** This project is under active early-phase development. No user should assume the platform is ready for production processing until relevant roadmap phases (through Phase 16) are completed and validated.

- **Production Deployment Support:** Commercial production deployment support is not currently offered or guaranteed.
- **Paid Support:** Paid consulting or enterprise support agreements are not currently available.

---

Thank you for your interest in the platform! We appreciate community contributions and feedback.
